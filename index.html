    Deploy ke Vercel (Tanpa Pengguna Input API Key)

    Cara Paling Praktis (Cukup 1 File index.html di Vercel):

    Tempelkan Gemini API Key Anda (format baru berawalan AQ. dari Google AI Studio) sekali saja di bawah, lalu unduh index.html siap Vercel. Saat diunggah ke Vercel, guru & siswa langsung bisa membuat soal tanpa diminta API Key lagi:

    Status: API Key Tersimpan di Browser

    Catatan Key AQ.: Pastikan pembatasan API pada kunci di Google AI Studio / Cloud Console mengizinkan Generative Language API.

    Alternatif (Jika Memakai Folder api/ di Vercel):

    Simpan file api/gemini.js di proyek Vercel dan isi GEMINI_API_KEY (key AQ.) di Environment Variables.
